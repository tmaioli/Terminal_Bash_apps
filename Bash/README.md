# Bash Scripts Directory

This directory contains Bash scripts for Linux environment configuration, automation, and system utilities.

## 📁 Contents

- **Notes.md** - Guide for creating directories on GitHub web interface

## 🐚 Planned Scripts

The following Bash scripts are planned for this directory:

- System information gathering (Linux equivalent of the PowerShell script)
- Environment configuration scripts
- Terminal optimization utilities
- Routine maintenance automation

## 🔧 Usage

Scripts in this directory are designed for Linux environments (tested on Ubuntu). Each script should be made executable before running:

```bash
chmod +x script_name.sh
./script_name.sh
```

## 📝 Notes

- Git does not track empty directories. This README.md file ensures the Bash directory is preserved in the repository.
- Refer to `Notes.md` for guidance on creating directory structures via GitHub's web interface.
